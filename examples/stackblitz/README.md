# react-github-readme-md — StackBlitz demo

A minimal Vite + React + TypeScript app that renders any GitHub repo's README in real time. Edit the `username` / `repo` inputs to point at a different repository.

## Open it live

➔ **[Open in StackBlitz](https://stackblitz.com/github/lacymorrow/react-github-readme-md/tree/main/examples/stackblitz?file=src/main.tsx)**

## Run locally

```bash
cd examples/stackblitz
npm install
npm run dev
```
